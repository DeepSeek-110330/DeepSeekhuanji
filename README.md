# 数学知识银河 (Math Knowledge Galaxy)

一个**3D 星系式的数学知识可视化网站**：每个光点是一个数学知识点，点击即可展开完整内容（中英双语定义、公式、性质、例题、代码实时绘制的配图）。

纯前端项目——HTML + CSS + JavaScript，**无后端、无数据库、无构建步骤**。

**🌐 在线版（已发布）**：<https://deepseek-110330.github.io/DeepSeekhuanji/> ——仓库：<https://github.com/DeepSeek-110330/DeepSeekhuanji>

---

## 快速开始

```bash
cd 数学知识银河
python3 -m http.server 8123
```

浏览器打开 <http://localhost:8123>

> **必须用本地服务器**，不能直接双击 `index.html`——浏览器会因 CORS 拦截 `fetch` 读取本地 JSON 与 ES 模块。
>
> 端口建议用 **8123**：之前所有开发和缓存都是在 8123 上，换端口会导致本地 vendor 资源重新缓存。

## 功能

| 功能 | 说明 |
|---|---|
| **银河星图** | 知识点按学科分支分布在螺旋旋臂上，每分支一种颜色 |
| **点击点亮** | 点击光点 → 相机飞过去 → 右侧展开完整内容 |
| **双语切换** | 面板右上角「EN / 中文」一键切换中英文内容 |
| **公式渲染** | KaTeX 渲染 LaTeX 公式 |
| **12 种数学图表** | 函数图、几何图、等高线、向量场、共形映射、斜率场、坐标轴、散点图、数值积分、3D 曲线、3D 曲面、单位圆——全部用代码实时绘制，可缩放不模糊 |
| **搜索** | 按标题/摘要/标签搜索，标题精确匹配优先；支持键盘导航（↑↓ 选择、Enter 进入、Esc 关闭） |
| **链接跳转** | 面板内链接可飞往相关知识点；悬停时银河中高亮其路径，支持「← 返回上一个」 |
| **例题折叠** | 例题默认收起，点「看解答」展开 |
| **公式一键复制** | 每个公式旁有复制按钮，一键拿到 LaTeX 源码 |
| **随机漫游** | 一键随机飞往某个知识点，适合闲逛 |
| **沉浸细节** | 光点呼吸、入场渐显绽放、分支旋臂脊线、面板等级徽章（L# ★） |
| **学习路线** | 6 条精选路线（微积分主线 / 线代十二步 / 概率统计 / 走向勒贝格 / 四支柱 / 图论与优化），逐步走、银河聚焦 |
| **分享与直达** | 每个知识点可复制直达链接（`#id`）；搜索命中点在银河中脉冲闪烁；旋臂末端显示分支名 |
| **知识共鸣（v=29）** | 点左下「知识共鸣」或按 `R`，依次点两颗星：星体投影沿弧线相撞，按链接图给出最短知识链与桥点；直接相邻时给出「共同关联」中的融合概念 |
| **推导卡（v=30）** | 点开结果卡的「为什么是这个结果？」：先给共同邻居排序/BFS 分层等图结构推导，再给精选数学推导（含条件与反例）、概念对照和结果条目的核心公式 |
| **知识点推导（v=31）** | 已覆盖知识点的详情面板新增「推导 / Derivation」区：分步推导、KaTeX 渲染、默认展开、中英同步；首批微积分 33 个节点（D01~D05） |
| **星体微动** | 知识点光点以极慢、极小的幅度各自漂浮；悬停时直接相邻的节点轻微提亮，少量能量脉冲沿连线飞行 |
| **清爽收纳** | 底部按钮可一键收起（«）；搜索记录可折叠/清除（× 或 Esc）；旋臂标签可显示/屏蔽（默认收起，v=29） |
| **分支筛选** | 左下角「知识分支」面板可收放，点击分支只看该分支 |
| **性能自适应** | 帧率低时自动降低渲染分辨率 |

## 数据格式速览

运行时只读 `data/knowledge.json`：

```jsonc
{
  "meta": { "title": "数学知识银河", ... },
  "branches": {
    "calculus": { "name": "微积分", "nameEn": "Calculus", "color": "#d16bff" }
  },
  "nodes": [
    {
      "id": "derivative",              // 全局唯一
      "title": "导数", "titleEn": "Derivative",
      "branch": "calculus",            // 必须属于 branches 里的键
      "level": 4,                      // 1~5，影响星点大小与位置
      "summary": "…", "summaryEn": "…",
      "definition": "…（支持 **粗体** 与 $公式$、$$独立公式$$）",
      "definitionEn": "…",
      "formulas": [{ "latex": "…", "note": "…", "noteEn": "…" }],
      "expression": { "text": "…", "symbol": "…", "note": "…", "noteEn": "…" },
      "properties": ["…"], "propertiesEn": ["…"],   // 中英数量必须一致
      "plot": { "type": "function", … },            // 可选
      "examples": [{ "problem": "…", "solution": "…" }],
      "tags": ["…"],
      "links": ["另一个知识点的 id"]                 // 必须真实存在
    }
  ]
}
```

完整规范见 `data/SCHEMA.md`。

## 开发者须知（重要）

- **改了 `js/` 下的任何文件，必须提升版本号**：把 `index.html`、`js/app.js`、`plot-test.html` 里的 `?v=N` 统一改成 `?v=N+1`。否则浏览器会继续用旧缓存，改动看不到。
  （当前版本：**v=31**）
- 知识点数据用 `fetch(..., { cache: "no-cache" })` 加载，每次都会向服务器校验，**加完知识点刷新即可看到**。
- 加知识点后要跑合并脚本：

  ```bash
  cd data
  python3 merge.py     # 校验 + 合并所有 batch*.json → knowledge.json
  ```

  脚本会检查字段完整性、id 冲突、非法分支、坏链接、绘图类型，**有错会拒绝写入**。

- **内容更新后还要生成运行时分片**：`python3 data/build_runtime.py`（首屏骨架 + 详情分片，v=19 起）。

- **上线**：`git add -A && git commit -m "…" && git push`；GitHub Pages 约 40 秒后自动重建（网络注意见 `WORKFLOW.md`「1.2 发布与更新」）。

更多细节（如何继续生成内容、历史踩过的坑）见 **`WORKFLOW.md`**，当前进度见 **`REPORT.md`**。
